# Ревью та оновлення v2 — 16.08.2026

Повний огляд стану після редизайну «вариант 1» (Codex, 12.08) і перелік змін цієї ітерації.

## Ревью попередньої версії

### Що вже було добре
- Чистий engine без DOM із незмінюваним станом та інваріантом відсортованої лінії.
- Tap-first управління замість ненадійного drag-and-drop.
- Локальні шрифти (Manrope) та іконки (Phosphor) — нуль зовнішніх залежностей.
- Ілюстрована дизайн-система у стилі настільної гри: 5 категорій, яскраві кольорові поля.
- Юніт + E2E тести, чиста консоль, відсутність overflow на 390×844.

### Знайдені проблеми (і що з ними зроблено)
1. **Одноразовий тап одразу розміщує картку.** На скрольній стрічці це гарантує випадкові помилки «пальцем» — і втрату життя. → Дворівневе розміщення: тап показує картку-прев'ю на місці, підтвердження другим тапом або кнопкою.
2. **Гра-одноденка: один режим, одна складність.** 24 події швидко вичерпуються. → 59 подій, 3 режими, 3 рівні складності, рекорди.
3. **Помилка пояснювалась слабко:** текст «правильне місце показано» без вказівки, де саме. → Бейдж «правильне місце» на скоригованій картці, автоскрол до неї, фідбек із роком і відстанню від правильної позиції.
4. **Скоринг не заохочував ризик:** розміщення у «щільний» проміжок (як радять правила настільної Timeline) нічим не відрізнялось. → Бонус +50 за влучання між сусідами ближче 50 років, множник ×1.5 на складному.
5. **Нема жодної допомоги гравцю** — при незнанні події лишалась вгадайка. → 2 підказки за партію (половина століття, −50 очок).
6. **`icon` (емодзі) у каталозі — мертве поле** після редизайну. → Видалено, натомість `difficulty` 1–3.
7. **Переповнення нижньої панелі** (виявлено при перевірці): фіксовані fr-рядки грід-сітки не вміщали картку+кнопки на 812px. → Панель тепер auto-розмірна, стрічка займає решту; окремий медіа-запит для низьких екранів.
8. **Серія (streak) не було видно** — тільки в фіналі. → Лічильник із вогником у шапці, поповерхова анімація очок «+125».

## Що нового у v2

### Геймплей і механіка (game-engine.js)
- `buildDeck`: колода залежить від складності — легка бере загальновідомі події (difficulty 1) і розводить їх мінімум на 25 років; складна включає експертні події та природні «щільні» кластери.
- Режими: **Класика** (10 подій), **Марафон** (всі 59), **Виклик дня** (сід із дати — однакова партія для всіх).
- Скоринг: 100 базових + серія до +100 + «щільний проміжок» +50, ×1.5 на складному.
- Підказки: `useHint` — 2 за партію, −50 очок, формат «Друга половина XVIII століття».
- `lastResult` розширено: `correctGap`, `positionDelta`, розбивка бонусів — UI пояснює помилку.
- `mistakes` — список подій для блоку «Запам'ятай» у фіналі.

### Контент (events.js)
- 24 → **59 подій** від 911 до 2022 року, всі з `difficulty` і перевіреними датами.
- Покриття: кожна категорія ≥5 подій, легкий пул ≥12; події з однаковим роком (1918, 1996, 2022) підтримуються рушієм.

### UI та дизайн-система
- **Стартовий екран**: вибір режиму (3 картки) + складності (сегменти), рекорд для вибраної комбінації, коротке інтро.
- **Дворівневе розміщення** з карткою-прев'ю (пунктир + «????») прямо в стрічці.
- **Підказка** — жовтий чип на картці + кнопка поруч із основною дією.
- **Анімації**: приземлення картки, розбите серце, вогник серії, флоат очок; все під `prefers-reduced-motion`.
- **Фінал v2**: вердикт залежить від результату (бездоганно/перемога/поразка), «новий рекорд», блок помилок, «Зіграти ще раз» + «Змінити режим».
- Хаптика через `navigator.vibrate` (короткий тап — успіх, патерн — помилка).
- Рекорди в `localStorage` окремо на режим/складність.

### Управління
- Тап: вибір → прев'ю → підтвердження (другим тапом по прев'ю або кнопкою).
- Клавіатура: ← → перемикають позицію, Enter підтверджує, Esc скасовує вибір.
- URL-параметри `?mode=`, `?difficulty=`, `?seed=` — прямий запуск без стартового екрана (тести, поділені посилання).
