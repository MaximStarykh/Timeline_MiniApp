# Не загубись у часі

Мобільна solo-гра про хронологію української історії. Гравець бачить подію без року та обирає її місце між уже відкритими картками.

## Правила

- У партії 10 унікальних подій: одна стартова і дев’ять відповідей гравця.
- Правильна відповідь дає 100 балів і бонус за серію.
- Помилка забирає одне з трьох життів, показує рік і автоматично ставить подію у правильне місце.
- Партія завершується після всіх подій або після втрати трьох життів.

## Локальний запуск

```bash
python3 -m http.server 4173
```

Відкрий `http://127.0.0.1:4173/`.

## Перевірка

```bash
npm install
npm test
npm run test:e2e
```

`npm test` перевіряє чисте ігрове ядро та каталог подій. `npm run test:e2e` проходить повну партію в Chromium з мобільним viewport 390 × 844.

## Поточний scope

Це навмисно вузький solo MVP без Telegram SDK, мультиплеєра, акаунтів, backend і монетизації. Перший етап перевіряє саме механіку, доступність і стабільність стану гри.
